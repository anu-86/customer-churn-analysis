# Customer Churn Analysis Dashboard

## Project Overview

This project analyzes customer churn data using Microsoft Excel. The goal is to identify customer retention patterns and understand the factors that influence customer churn.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Data Cleaning
* Dashboard Design

## Project Objectives

* Analyze customer churn behavior.
* Identify factors affecting customer retention.
* Visualize churn trends using charts.
* Generate business insights and recommendations.

## Dashboard Components

### 1. Churn Distribution

Shows the number of customers who stayed and customers who churned.

### 2. Gender vs Churn Analysis

Compares churn behavior across customer genders.

### 3. Contract vs Churn Analysis

Analyzes churn patterns across different contract types.

## Key Insights

* Most customers remained with the company, while a smaller percentage churned.
* Male and female customers showed similar churn behavior.
* Month-to-month contract customers experienced the highest churn rate.
* Customers with one-year and two-year contracts showed stronger retention.
* Contract type is a major factor influencing customer churn.

## Recommendations

* Encourage customers to switch to long-term contracts.
* Implement retention programs for high-risk customers.
* Provide loyalty benefits and personalized offers.
* Monitor customer groups with higher churn rates.
